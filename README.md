# Магазин на Flutter

Приложение, имитирующее небольшой интернет-магазин.

## Возможности

- Добавление товара с обязательным изображением из галереи, названием, ценой, остатком и статусом продажи.
- Управление остатком, доступностью и безопасное удаление товара в админ-панели.
- Каталог синхронизирован с админ-панелью; покупка одним транзакционным действием уменьшает остаток и создаёт запись истории.
- История покупок с количеством, ценой на момент покупки и датой/временем.

Данные хранятся в памяти на время сессии. Проект организован по feature-first: товары и покупки содержат собственные модели, контракты и реализации хранилищ; `StoreController` координирует операции между ними. Поэтому постоянное хранилище или API можно подключить без изменения экранов.

## Запуск

```bash
flutter pub get
flutter run
```

## Тест

```bash
flutter analyze
flutter test
```

Для выбора фотографии нужно выдать приложению доступ к галерее.
